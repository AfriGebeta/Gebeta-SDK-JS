# Example apps

- **js/** – Static HTML examples for the Gebeta Maps JavaScript SDK. Serve the repo root and open `/apps/js/`. See [js/README.md](js/README.md).
- **react/** – React example using `@gebeta/maps-react` with `react-map-gl` and clustering. Run from repo root: `yarn dev:react` (or `yarn workspace react-example dev`). See [react/README.md](react/README.md).
