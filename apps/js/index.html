Gebeta Maps SDK - Examples

Examples for the Gebeta Maps JavaScript SDK (core + js package).

Directions

Get directions between two points with route display, waypoints, and turn-by-turn instructions.

Geocoding

Forward and reverse geocoding. Search by place name or look up address from coordinates.

Clustering

Marker clustering with customizable options. Add multiple markers and see them cluster automatically.

Fencing

Draw geofences/polygons on the map. Click to add points and create custom fence boundaries.

Fence Styling

Customize fence appearance with fill, line, and border styles. Try preset styles or create your own.

Navigation (High Precision)

Turn-by-turn navigation with WebSocket-based high-precision tracking. Real-time location updates with driver POV camera.

Navigation (Low Precision)

Turn-by-turn navigation with HTTP-based low-precision tracking. Periodic location updates for battery-efficient tracking.

Navigation Simulation

Simulated navigation with speed controls and visual instructions. Perfect for testing without GPS. Shows turn-by-turn UI.

Setup: Set your API key in config.js (GEBETA_API_KEY). Build the SDK from repo root with yarn build, then serve this folder (e.g. npx serve . from repo root and open /apps/js/).

Using a bundler (Vite/webpack)? Import only what you need instead of the full bundle:

// Only geocoding — no directions/clustering/navigation in your bundle
import { GeocodingManager } from '@gebeta/js/geocoding';

// Only directions
import { DirectionsManager } from '@gebeta/js/directions';

// Only clustering
import { ClusteringManager } from '@gebeta/js/clustering';

See apps/react/src/App.tsx for a full example.
